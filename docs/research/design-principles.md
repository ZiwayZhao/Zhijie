# 智阶产品设计核心理念

## 用户原话
"在文字端给出用户最好的教育，超越用户上传的文本"
"文字是吸收信息最快的方式。不要养成依赖音频和视频的惰性。"

## 参考案例：苏格拉底·七（ostep-socratic-tutor）

### 核心验证结论
- 学习效率提升3倍（10小时顶过去30小时）
- 学习吸引力提升到3A大作水平
- 关键不是AI课堂播放，而是**苏格拉底式一对一问题引导**

### 为什么苏格拉底式教学如此有效
1. **全程问题驱动**：AI不讲课，而是不断提问，学生自己推理出知识全貌
2. **即时反馈**：每个知识点都要学生回答，不是被动阅读
3. **递归教学**：发现薄弱点→逆向追溯到底层缺陷→补齐后回到原题
4. **无限耐心**：学生可以连续问4-5个问题，AI不会不耐烦
5. **情感陪伴**：AI教练有人设和情感，学习变成"想见到她们"

### 关键设计启示
1. **文字>视频**：p2作者验证"文字学习效率极高"，看视频总是不耐烦
2. **不做游戏化数值**：XP/徽章沦为无聊的数值游戏。真正有效的是"友谊和陪伴"
3. **人设有温度**：AI教练应有一致的性格和情感，不是冷冰冰的工具
4. **习题嵌入教学**：每节课知识讲解后要有做题环节
5. **复习要分散**：间隔重复（FSRS）比集中复习更有效

## 对智阶的指导

### 我们要做的
- ✅ 苏格拉底式LLM对话（不给答案，用问题引导）
- ✅ 文字为主的高效学习体验
- ✅ AI教练有一致的人设和温度
- ✅ 递归式薄弱点追踪（测验错题→逆向追溯→补齐）
- ✅ 间隔重复（FSRS闪卡）嵌入学习流程
- ✅ 简化动线：上传→分析→一键开始→自动编排学习步骤

### 我们不做的
- ❌ AI课堂播放（OpenMAIC式的被动听课）
- ❌ TTS语音教学（文字更高效）
- ❌ 花哨的游戏化数值系统
- ❌ 复杂的多步骤手动操作

## 对比 OpenMAIC 的核心差异

| | OpenMAIC | 智阶 |
|---|---------|------|
| 模式 | AI老师在讲台上讲课（被动） | AI教练一对一引导（主动） |
| 核心循环 | 听→看→偶尔互动 | 问→答→纠→再问→记 |
| 参与度来源 | AI同学+语音多模态 | 苏格拉底式提问+情感陪伴 |
| 信息载体 | 语音+白板+动画 | 高质量文字+公式渲染 |
| 长期记忆 | 无 | FSRS间隔重复 |
| 薄弱点处理 | 统一课堂节奏 | 递归追溯到底层缺陷 |
