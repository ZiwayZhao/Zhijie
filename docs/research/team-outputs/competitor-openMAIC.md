# 竞品研究：OpenMAIC
> 研究日期：2026-03-18

## 产品概述

OpenMAIC（Open Multi-Agent Interactive Classroom）是清华大学 THU-MAIC 团队开源的多智能体 AI 课堂平台。核心理念是"1 个课件 + 2 美元 + 30 分钟 = 一堂完整互动课"。用户上传 PDF 或输入主题描述，系统自动生成包含 AI 教师语音讲解、AI 同学互动提问、白板绘图、测验、交互式模拟的沉浸式课堂。

技术栈：Next.js 16 + React 19 + TypeScript + Tailwind CSS 4 + LangGraph 1.1（多智能体编排）。支持多 LLM 提供商（OpenAI、Anthropic、Gemini、DeepSeek）。已在清华内部覆盖 2000+ 学生，10 万+ 交互记录，学生满意度 92%。

**核心定位差异**：OpenMAIC 做的是"AI 课堂"（模拟真实授课场景），智阶做的是"AI 学习工作台"（个人化工具 + 记忆系统）。两者面向同一材料输入，但产出形态完全不同。

## 用户旅程图

```
用户输入（2种方式）
  ├── A. 上传 PDF 课件
  └── B. 输入主题文字描述
         │
         ▼
  ┌─────────────────────────┐
  │  Step 1: 提交生成请求     │  ← 用户唯一操作：点"开始生成"
  │  （无需选择学习模式/意图） │  ← AI 自动决定一切
  └─────────────────────────┘
         │
         ▼ 异步处理（约30分钟，后台轮询）
  ┌─────────────────────────┐
  │  Stage A: Lesson Planner │  解析文档 → 生成结构化大纲
  │  Stage B: Content Gen    │  大纲 → 幻灯片+语音脚本+测验+模拟
  └─────────────────────────┘
         │
         ▼
  ┌─────────────────────────┐
  │  Step 2: 进入课堂         │  ← 课堂 URL: /classroom/[id]/
  │  开始沉浸式"听课"        │
  └─────────────────────────┘
         │
         ▼ 课堂中的交互
  ┌─────────────────────────────────────┐
  │  AI 教师: TTS 语音讲解 + 白板绘图     │
  │  AI 同学: 随机举手提问/参与讨论        │
  │  用户: 随时插话/被点名/做测验          │
  │  圆桌辩论 / PBL 项目 / 交互式模拟     │
  └─────────────────────────────────────┘
```

**关键观察：用户从上传到"听课"只需 2 步操作（上传 → 等待 → 进入课堂），没有中间配置步骤。** 系统不要求用户选择"学习模式"或"学习意图"——AI 自动完成所有教学设计决策。

## 关键设计决策分析

### 1. 零配置生成（Zero-Config Generation）
**描述**：用户只需上传文件或输入主题，无需选择模式、难度、时长等参数。AI 全权决定课程结构。
**为什么有效**：消除决策疲劳，降低上手门槛到极致。对于不确定自己需要什么的学生尤其友好。
**代价**：牺牲了个性化——所有人得到相同的课堂，无法根据"备考"vs"学透"调整重点。

### 2. 多角色社交模拟（Multi-Agent Social Simulation）
**描述**：课堂不是一对一辅导，而是模拟真实教室——有老师讲课、有同学提问、有圆桌讨论。
**为什么有效**：解决在线学习最大痛点"孤独感"。AI 同学的随机提问制造了"社交压力"，迫使注意力集中。类比：健身房比家里跑步机效果好，因为有人在旁边。
**数据支撑**：结业率 40%（vs MOOC 5%），清华团队归因于"AI 同学的陪伴感和互动压力"。

### 3. 多模态课堂播放引擎（Agentic Playback Engine）
**描述**：不是静态 PPT 或文本阅读，而是"L4 自动驾驶式课堂"——AI 自动判断何时讲解、何时讨论、何时补充细节，支持 28+ 种 Action 类型（语音、白板绘图、激光笔高亮、图表等）。
**为什么有效**：MOOC"像定速巡航"，OpenMAIC"像 L4 自动驾驶"。动态节奏防止走神。

### 4. 30 分钟异步生成 + 即用型课堂
**描述**：生成时间约 30 分钟，成本约 2 美元。生成完成后，课堂是一个完整的可回放实体。
**为什么有效**：将"等待"与"使用"完全解耦。用户提交后可以去做别的事，回来直接上课。
**问题**：30 分钟等待期的体验设计细节不明——搜索到的资料中没有提到进度条、预览或通知机制的具体实现。

### 5. 开放集成生态
**描述**：通过 OpenClaw 集成飞书/Slack/Telegram，用户可在聊天工具中直接触发课堂生成。支持导出 PPT 和独立 HTML。
**为什么有效**：降低工具切换成本，课堂内容可复用。

## 与智阶的对比

| 维度 | OpenMAIC | 智阶当前 | 智阶应改进到 |
|------|---------|---------|-----------|
| **核心形态** | AI 课堂（模拟授课） | AI 工作台（个人工具） | 保持工作台定位，但借鉴"即时开始"体验 |
| **输入到产出步数** | 2 步（上传→进入课堂） | 5+ 步（上传→选课程→选材料→选工具→等待→阅读） | 目标 2-3 步 |
| **用户需要做的决策** | 零决策，AI 全自动 | 多决策（选工具、选模式） | 智能默认 + 一键开始，高级选项折叠 |
| **等待体验** | ~30min 异步，细节不明 | 2-5min 拆解，无进度反馈 | 流式进度 + 先出先看 |
| **学习模式** | 统一课堂，无模式选择 | 设计了学透/备考/复习但未实现 | 意图引导 + 自动推荐模式 |
| **社交元素** | AI 同学互动（核心卖点） | 无 | 远期可考虑 AI 学伴 |
| **个性化** | 弱（所有人相同课堂） | 强（BKT + FSRS + 个人工具链） | 保持优势，这是智阶的差异化 |
| **内容形态** | 多模态课堂（语音+白板+动画） | 文本为主（Markdown + PDF） | 短期保持文本，中期加语音 |
| **记忆/复习** | 无（课堂是一次性的） | FSRS 闪卡系统 | 持续强化，这是智阶的护城河 |
| **技术栈** | Next.js 16 + LangGraph | Vite + React + FastAPI | 保持当前栈 |

## 可借鉴的具体设计模式

### 1. "一键开始"模式（高优先级）
**OpenMAIC 做法**：上传后零配置直接生成。
**智阶移植方案**：上传材料后，系统自动推荐"最可能的学习模式"（根据材料类型 + 考试日期推断），用户只需确认一键开始。高级选项（选工具、调参数）折叠在二级入口。

### 2. 异步生成 + 先出先看（高优先级）
**OpenMAIC 做法**：提交后异步处理，完成后进入课堂。
**智阶移植方案**：拆解任务提交后，第一个模块完成即可开始阅读，不必等全部完成。SSE 推送"模块 1/5 已就绪，点击开始阅读"。比 OpenMAIC 30 分钟等待体验更好。

### 3. 多角色互动元素（中优先级，远期）
**OpenMAIC 做法**：AI 同学随机提问制造互动。
**智阶移植方案**：在精读模式中加入"AI 学伴"角色，偶尔弹出"你觉得这个概念和 XX 有什么关系？"式的苏格拉底提问。不是完整课堂模拟，而是轻量级互动节点。

### 4. 导出与复用能力（低优先级）
**OpenMAIC 做法**：支持导出 PPT 和 HTML。
**智阶移植方案**：精讲 Markdown 支持导出为 PDF 笔记或 Notion 格式，方便学生课后复习分享。

### 5. 课堂节奏自适应（中优先级）
**OpenMAIC 做法**：Agentic 播放引擎根据内容自动调整讲解/讨论/练习的节奏。
**智阶移植方案**：学习计划执行器根据测验结果和停留时间动态调整下一步（跳过已会的、插入补讲）。这与智阶 Phase 4 HTN 规划器的目标一致。

## 结业率 40% 的核心归因

根据清华团队公开资料和 36kr 深度报道，结业率 8 倍于 MOOC 的关键因素：

1. **社交压力机制**：AI 同学的存在创造了"有人在看"的心理暗示，类似健身房效应
2. **动态节奏**：不是匀速播放，而是根据内容自动切换讲解/讨论/练习模式，减少走神
3. **即时反馈**：测验自动判分 + AI 助教个性化点评，而非 MOOC 的延迟反馈
4. **低门槛**：生成后直接"听课"，不需要学生做任何复杂操作
5. **课堂完整性**：一堂课是完整闭环（讲解→互动→测验→总结），而非 MOOC 的"看了前两集就弃"

**对智阶的启示**：智阶的"个人工具台"模式天然缺乏社交压力，需要通过其他机制（闪卡到期提醒、连续学习天数、考试倒计时紧迫感）来替代。
