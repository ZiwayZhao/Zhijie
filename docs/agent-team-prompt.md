# Agent Team 研究任务：智阶产品动线优化

## 核心问题（用户原话）
"产品侧的动线不明确，复杂，且无法确定真实能帮助到用户的目标。需要针对用户的不同需求，简化流程，清理动线，优化体验。"

## 竞品参考：OpenMAIC（清华开源AI课堂）
- 多Agent课堂模拟（AI老师+AI同学互动提问）
- 课堂结业率40%（MOOC仅5%）
- "1个课件+2美元+30分钟=一堂课"的极简动线
- 用户只需：上传PDF → 等待生成 → 观看互动课堂

## 任务分工

### 你作为 Team Lead 负责：
1. 阅读 docs/workbench-audit-2026-03-17.md（审计报告）
2. 阅读关键代码文件理解当前产品动线
3. 协调 teammates 讨论以下问题

### 讨论主题（请分配给 teammates 并要求他们互相讨论）：

**Topic 1：当前动线诊断**
- 梳理从"打开工作台"到"完成学习"的完整步骤数
- 标记每一步的用户决策成本和摩擦点
- 对比 OpenMAIC 的动线（仅3步：上传→等待→学）

**Topic 2：用户场景拆分**
- 场景A：考前冲刺（2天后考试，只想快速过考点）
- 场景B：深度学习（想真正理解这门课）
- 场景C：日常复习（已学过，防遗忘）
- 每个场景的最短路径是什么？

**Topic 3：动线简化方案**
- 如何实现"一键开始学习"？
- 哪些步骤可以合并/省略/自动化？
- AI应该替用户做哪些决策？

**Topic 4：前端交互重设计**
- 工作台布局如何配合简化后的动线？
- 学习流程如何自动流转而非手动点击？
- 进度可视化如何让用户有掌控感？

**Topic 5：体验细节打磨**
- 每个触点的微交互设计
- 加载状态的优化
- 错误/异常情况的优雅处理
- 学习完成后的成就感设计
