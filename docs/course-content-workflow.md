## 一、产品定位与内容调性

### 1.1 平台定位
智阶是面向**中国留学生 + 国内 CS 自学者**的课程知识社区。
用户画像：大学生、考研/出国准备者、转码自学者。

### 1.2 内容调性
- **客观学术**：不用营销话术（"最好的"、"必学的"）
- **简洁信息密度高**：2-3 句话说清楚课程是什么、学什么、谁适合
- **中文为主**：课程名保留原文（如 MIT 18.06），描述用中文
- **实用导向**：突出"学完能做什么"，而非"这门课多有名"

### 1.3 禁止项
- 不抄袭 csdiy.wiki 原文（需改写）
- 不编造课程没有的内容
- 不使用感叹号、emoji
- 不写"本课程"（直接说课程名或省略主语）

## 二、课程详情页字段规范

### 2.1 必填字段

| 字段 | 规范 | 示例 |
|------|------|------|
| **name** | 保留原课程名，中英文均可 | "MIT 18.06 Linear Algebra" |
| **platform_description** | 2-3 句话，≤150 字 | 见下方模板 |
| **learning_objectives** | 3-5 条，动词开头 | ["掌握矩阵运算与向量空间", ...] |
| **target_audience** | 1 句话，含前置要求 | "理工科大一学生，需高中数学基础" |
| **tags** | 3-8 个，英文小写，连字符 | ["linear-algebra", "mit", "undergraduate"] |
| **difficulty** | 1-5 星 | 3 |
| **category** | 从已有分类选择 | "Fundamental Mathematics" |

### 2.2 选填字段

| 字段 | 说明 |
|------|------|
| **estimated_hours** | 仅在有明确数据时填写 |
| **prerequisites** | 从课程原始描述提取 |
| **semester** | 如 "Fall 2011" |
| **level** | undergraduate / graduate |
| **syllabus** | JSON 结构化大纲（后续补充） |

### 2.3 platform_description 写作模板

```
模板 A（有大学+讲师的经典课程）：
"{大学}的{课程主题}课程，由{讲师}讲授。覆盖{核心内容1}、{核心内容2}等主题，{课程特色/亮点}。"

模板 B（工具/技能课）：
"系统学习{技能/工具}的实践课程。从{起点}出发，逐步掌握{核心技能}，适合{目标人群}。"

模板 C（无明确大学的通用课程）：
"面向{目标人群}的{课程主题}课程。{核心内容概述}，{课程特色}。"
```

### 2.4 learning_objectives 写作规范

- 用"掌握"、"理解"、"能够"、"运用"开头
- 每条 ≤25 字
- 从具体到抽象排列
- 不超过 5 条

## 三、课程生命周期

```
         手动创建
            │
            ▼
┌─────────────────────┐
│       draft         │ ← 编辑创建中（不可见）
└──────────┬──────────┘
           │ 完善信息
           ▼
┌─────────────────────┐         ┌──────────────┐
│        raw          │ ← ──── │ 爬虫导入     │
└──────────┬──────────┘         └──────────────┘
           │ 内容洗稿（人工/AI）
           ▼
┌─────────────────────┐
│   ai_rewritten      │ ← 已有平台描述（待审核）
└──────────┬──────────┘
           │ 编辑审核通过
           ▼
┌─────────────────────┐
│     reviewed        │ ← 编辑确认（可发布）
└──────────┬──────────┘
           │ 发布
           ▼
┌─────────────────────┐
│     published       │ ← 对用户可见
└─────────────────────┘

异常路径：
- raw → rewrite_failed（洗稿失败）→ raw（重试）
- ai_rewritten → rejected（内容不合格）→ raw（重新洗稿）
- published → archived（下架）
- published → reviewed（需要修改）
```

## 四、内容洗稿规则

### 4.1 csdiy.wiki 课程洗稿

**输入**：csdiy 原始描述（中文，通常 3-10 行，含课程介绍段落）
**输出**：platform_description + learning_objectives + target_audience

**规则**：
1. 提取核心信息：大学、讲师、语言、核心主题
2. 用模板 A/B/C 重写为 2-3 句话
3. 从描述/先修要求推断 learning_objectives
4. 从难度/先修要求推断 target_audience

### 4.2 MIT OCW 课程洗稿

**输入**：OCW 英文 HTML description + course_features + topics
**输出**：中文 platform_description + learning_objectives + target_audience

**规则**：
1. HTML → 纯文本
2. 翻译为中文
3. 套用模板 A（MIT OCW 几乎都有大学+讲师）
4. 从 course_features 推断可用资料类型（讲义、习题、考试等）

### 4.3 质量标准

| 维度 | 合格标准 |
|------|---------|
| 长度 | platform_description: 50-150 字 |
| 准确性 | 不包含课程没有的内容 |
| 独立性 | 不依赖 csdiy.wiki 原文即可理解 |
| 完整性 | learning_objectives ≥ 3 条 |
| 标签 | tags ≥ 3 个且相关 |

## 五、审核流程

### 5.1 自动审核（脚本检查）
- [ ] platform_description 长度 50-150 字
- [ ] learning_objectives 数量 3-5
- [ ] target_audience 非空
- [ ] tags 数量 ≥ 3
- [ ] 无禁止词（"最好的"、"必学"、"!"）

### 5.2 人工审核（编辑抽查）
- 首批洗稿：100% 审核
- 后续批次：20% 抽查
- 审核标准：准确性 > 可读性 > 风格一致性

### 5.3 发布策略
- **Phase 1**：洗稿完成 + 自动审核通过 → `ai_rewritten`
- **Phase 2**：人工审核通过 → `reviewed`
- **Phase 3**：批量发布 → `published`
- 首批先做 top 50 课程（按 csdiy 热度/完整度排序）
