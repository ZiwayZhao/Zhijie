## 一、产品定位（终稿）

**一句话**：智阶是**苏格拉底式 AI 学习教练**——通过问题引导而非讲授，帮大学生高效掌握课程知识，并用 FSRS 间隔重复锁定长期记忆。

**核心理念**（创始人+用户验证）：
1. **文字是最高效的学习方式** — 不做 TTS/视频（教育从业者验证负面效果）
2. **苏格拉底式问题引导 > AI 讲课** — AI 不给答案，用问题引导学生自己推理（效率 3 倍）
3. **情感陪伴 > 游戏化数值** — 不做 XP/排行榜，做有温度的 AI 教练（Duolingo 的教训）
4. **递归式薄弱点追踪** — 答错→追溯底层缺陷→正向苏格拉底补齐→回到原题
5. **FSRS 间隔重复** — 竞品都没有的长期记忆锁定系统

**vs 竞品**：
| | OpenMAIC | Khanmigo | NotebookLM | **智阶** |
|---|---------|----------|------------|---------|
| 模式 | AI课堂（被动听） | 嵌入式辅导 | 文档对话 | **苏格拉底教练（主动练）** |
| 到第一价值 | 2步 | 2-3步 | 2-3步 | **目标 2-3步**（当前17步） |
| 个性化 | 无 | 依赖课程树 | 无 | **BKT+FSRS（最强）** |
| 长期记忆 | 无 | 无 | 无 | **FSRS自进化闪卡** |
| 知识社区 | 无 | Khan封闭体系 | 无 | **知识网络（中期）** |

## 二、动线简化（R1 成果）

### 2.1 当前问题诊断

**核心问题不在 UI，在架构**：三种学习场景共享同一管道，零差异化。

代码级证据：
```typescript
// 1. API 不接受 intent
body: JSON.stringify({ material_id: materialId })  // intent 未传

// 2. gathering 数据被丢弃
const startProcessing = async (_data?: GatheringData) => { ... }

// 3. review 被映射为 learn
const intentForBackend = intent === 'review' ? 'learn' : intent
```

**当前步骤**：17步 · 8个用户决策点 · 5-8分钟到第一价值
**最大摩擦点**：2-5分钟纯等待（致命级）> 意图选择认知门槛 > 模块间手动导航

### 2.2 三路径分叉方案

#### 路径 A：考前冲刺（10步 → 2步）

**关键区分**（创始人强调）：备考冲刺 ≠ 复习。很多学生冲刺时**没学过任何东西**，本质是"加速学习通过考试"。

```
[选"备考冲刺"] → [考点速览 + 流式精讲]
  ↓ AI 自动：
  - 跳过 gathering（数据被丢弃）
  - 跳过 plan-preview（焦虑用户不需要5步计划）
  - 管道启动，第1个模块就绪立即展示
  - 按 exam_weight 排序，优先高权重+薄弱模块
```

#### 路径 B：深度学习（10步 → 3步）

```
[选"学透"] → [等待+先看原文] → [确认计划 → 自动连续学习]
  ↓
  跳过 gathering（掌握度由 BKT 自动推断）
  保留 plan-preview（深度学习需要 ownership）
  模块底部"下一模块"自动引导
```

#### 路径 C：日常复习（10步 → 1步）

**关键区分**：复习 = 知识已掌握，防遗忘。直接走 FSRS 闪卡。

```
[选"快速复习"] → 直接进入 FSRS ReviewSession
  ↓ 完全绕过 disassembly 管道
  ├── 有到期闪卡 → ReviewSession
  ├── 有分析结果但无闪卡 → 自动从精讲+测验生成闪卡
  └── 无分析结果 → "请先分析材料"
```

## 三、苏格拉底对话引擎（R2 成果）

### 3.1 从模板制升级为 LLM 驱动

| 维度 | 模板制（当前） | LLM 驱动（目标） |
|------|-------------|-----------------|
| 路径空间 | 有限（设计时穷举） | 无限（实时生成） |
| 追问深度 | 固定 3-4 层 | 可递归到任意深度 |
| 错误诊断 | "答案对/错" | 理解学生*为什么*错 |
| 知识迁移 | 不能跨模块关联 | 自由关联不同概念 |

### 3.2 System Prompt 三层架构

```
Layer 1（固定）: 教练人设 + 苏格拉底方法论
  - 永远不直接给答案，用提问引导
  - 每次最多 1-2 个引导性问题
  - 认可在前纠正在后
  - 禁止："很好的问题！"（AI slop）

Layer 2（动态）: 知识锚定（Specialist Markdown）
  - 防幻觉：所有回答基于教材内容
  - 可引用具体页码/模块

Layer 3（动态）: 学生状态
  - BKT mastery → 脚手架等级
  - 会话历史 → 上下文连贯
  - 错题记录 → 针对性追问
  - 导师记忆 → 个性化教学
```

### 3.3 ARKT 递归薄弱点追踪算法

```
触发：quiz_score < 60% 或 socratic 连续 3 次无法回答
  │
  ├─ 1. 提取失败概念
  ├─ 2. LLM 推断前置概念（2-4 个）
  ├─ 3. 正向苏格拉底探测（非逆向考试！）
  │     ├─ SOLID → 标记已掌握
  │     ├─ SHAKY → 递归追踪（最多 3 层）
  │     └─ MISSING → 加入补讲队列
  ├─ 4. 从最底层开始正向教学
  └─ 5. 补齐后回到原始模块重新挑战
```

**关键设计**：用"正向苏格拉底"（从已知引向未知）而非"逆向考试"（连续暴露弱点），避免心理打击。

### 3.4 导师双层记忆系统

```
短期记忆（Session Memory）
  ├── 本次对话历史（最近 20 轮）
  ├── 递归追踪概念栈
  └── 即时情绪信号

长期记忆（Persistent Memory）
  ├── 学习风格（visual/verbal/analytical）
  ├── 偏好解释方式（举例/类比/公式推导）
  ├── BKT mastery + FSRS 状态
  ├── 历史错题模式聚类
  └── 有效教学策略记录
```

会话开始时注入：*"你和这位同学已一起学习了 {n} 次，共 {m} 分钟。上次学到 {x}。这位同学的特点：{style}型，容易犯的错是 {patterns}。"*

### 3.5 四个情感触点（学术陪伴，非情感依赖）

| 触点 | 时机 | AI 回应 |
|------|------|--------|
| 困难共情 | 连续答错 | "这个概念确实难，很多人第一次都卡在这里。我们换个角度？" |
| 进步认可 | mastery 提升 | "你对[概念]的理解明显深入了——上次你在[具体点]卡住，现在能自己推导了。" |
| 节奏感知 | 学习 90min+ | "你已经连续学了90分钟，明天 FSRS 会安排复习。" |
| 回归欢迎 | 多天未学 | "距上次学到[模块]已过5天，先做几张闪卡热热身？" |

**护栏**：AI 不主动发起对话、不模拟情绪波动、限定在学习范围、不给 AI 起名/设定外貌。

## 四、成就系统修正（R2 成果）

### 4.1 删除的元素（Duolingo 教训）
- ❌ XP 积分（奖励"完成"而非"掌握"）
- ❌ 排行榜（制造焦虑，学习是个人旅程）
- ❌ 每日签到奖励（奖励出现不奖励学习）
- ❌ 连续打卡天数强调（丢失记录导致放弃）

### 4.2 保留的元素（Anki 启示）
- ✅ mastery 进度环（真实知识状态，红→黄→绿）
- ✅ FSRS 记忆保留率可视化（"我确实记住了"）
- ✅ 知识地图着色（已掌握=accent-gold，未掌握=灰色）

### 4.3 新增 mastery 驱动成就（不可刷）

| 成就 | 触发条件 | 展示 |
|------|---------|------|
| 模块精通 | mastery ≥ 90% | 小金点 |
| 概念突破 | 连续3次错后首次对 | "突破了！" + accent-gold 闪光 |
| 闪卡毕业 | stability > 90 天 | "长期记忆" 标记 |
| 薄弱攻克 | <30% → >70% | "从薄弱到掌握" |
| 全课精通 | 全模块 mastery > 80% | 金色描边 |

## 五、FSRS 闪卡深度集成

### 5.1 四条生成路径
1. **精讲→卡**：Specialist Markdown 自动提取关键概念
2. **错题→卡**：Quiz 答错一键转闪卡（正面=题目，背面=答案+解析）
3. **对话→卡**：Socratic 对话中 AI 教练解释的核心概念
4. **标注→卡**：PDF 高亮文本一键生成

### 5.2 FSRS + ARKT 双向联动（独有护城河）
```
发现薄弱点 → 自动生成闪卡 → FSRS 调度复习
     ↑                                    ↓
  深度追踪  ←  复习失败  ←  再次触发 ARKT
```
竞品（OpenMAIC/Khanmigo/NotebookLM）都没有这个闭环。

### 5.3 自进化触发器
| 条件 | 动作 |
|------|------|
| 连续 Again ≥ 3 | LLM 拆分为子卡 |
| 连续 Easy ≥ 5 | 退役 |
| lapse_rate > 50% | LLM 改写问法 |
| 回答 > 15s | LLM 加助记提示 |
| 同模块 ≥ 3 张卡集体失败 | 补充前置知识卡 |

## 六、知识网络（R2 成果）

### 6.1 价值判断

**结论：有差异化价值，但 v1 不做前端社区。**

**支持论据**：
- Studocu 月活 5000 万证明"找到这门课的好资料"是刚需
- 跨校同课对比（TUM vs 清华的线代）是独特价值
- 竞品全部没有课程社区

**反对论据**：
- AI 生成能力正在侵蚀社区内容价值（Quizlet 共享卡组衰落）
- 冷启动成本极高（Studocu 用了 10+ 年）
- 中国保研竞争下同班共享意愿低

### 6.2 分阶段策略："先修路后通车"

| 阶段 | 做什么 | 不做什么 | 价值 |
|------|--------|---------|------|
| **v1** | 后台课程分类+学校映射（已有） | 前端社区、共享 | 数据积累 |
| **v2** | 课程发现页（浏览/搜索） | 排行、互相出题 | 用户获取 |
| **v3** | 跨校同课对比 + AI 推荐 | 同班共享 | 差异化 |
| **v4** | 知识图谱可视化 + 跨课程推荐 | — | 护城河 |

### 6.3 知识网络如何增强学习体验

```
知识网络不只是入口，而是学习路径的一部分：

学生学完"线性代数·矩阵运算"
  ↓ AI 发现：这个概念在"量子力学·态矢量"中也出现
  ↓ 推荐："你掌握了矩阵运算，量子力学的态矢量会更容易理解"
  ↓ 知识图谱中"线代→量子力学"的边变为 accent-gold

学生搜索"离散数学"
  ↓ 发现 3 所学校的材料：TUM(德语)、清华(中文)、MIT(英文)
  ↓ AI 推荐："TUM的材料侧重证明，清华的侧重应用，MIT的侧重算法"
  ↓ 学生选择最适合自己的版本
```

### 6.4 中国市场特殊性

- **跨校共享 > 同班共享**：没有直接竞争关系，分享意愿高
- **学习通/知到 的痛点**：只做内容分发，不做学习效果优化 — 智阶的机会
- **微信生态中已有非正式知识网络**（课程群、考研群）— 智阶可以正式化这些连接

## 七、视觉效果保障

### 7.1 砍的是摩擦，加的是质感

**删除的 UI 组件**（减步骤）：
- GatheringPhase 表单（数据被丢弃）
- review 场景的 ProcessingView（假流程）
- 考前场景的 plan-preview

**保留的核心视觉组件**：
- MaterialReader 精讲渲染（ReactMarkdown + KaTeX）
- PdfAnnotator（高亮+批注）
- QuizPanel（即时反馈）
- Editorial Academic 美学全部保留

**新增的视觉组件**（提升质感）：
- ProgressRail 顶部进度轨道（红色节点 + 暖色轨道）
- mastery 进度环（SVG 动画）
- 知识地图着色（accent-gold 已掌握节点）
- 闪卡 3D 翻转（Framer Motion perspective）
- "概念突破" accent-gold 闪光微动效
- 模块间 crossfade 过渡

### 7.2 设计原则不变
- `#A5192E` 红色主色调
- `#F7F5F2` 暖纸张色背景
- Instrument Serif 衬线标题 + Satoshi 无衬线正文
- Borders over Shadows
- 引用线风格 `border-l-3 border-l-red-primary`
- 庆祝像"论文被接收"——精准、克制、有分量

## 十、不做的事（明确边界）

| 不做 | 原因 |
|------|------|
| TTS 语音教学 | 教育从业者验证负面效果，文字更高效 |
