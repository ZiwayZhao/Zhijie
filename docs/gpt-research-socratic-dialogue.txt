  - 消息状态标记为 `interrupted`

**九、降级策略：Sonnet 4.5 -> Haiku 4.5**

建议降级触发条件：

- Sonnet 超时
- 429 / overload
- 非关键场景且延迟预算紧张
- 学生低价值闲聊或摘要任务

路由策略：

- 主对话：`claude-sonnet-4-5`
- 摘要压缩：`claude-haiku-4-5`
- Sonnet 异常重试 1 次后切 Haiku
- 若切 Haiku，需要降低响应上限，避免风格漂移

伪代码：

```python
async def generate_with_fallback(req: ClaudeRequest):
    try:
        return await anthropic_stream(model="claude-sonnet-4-5", req=req)
    except RetryableAnthropicError:
        return await anthropic_stream(model="claude-haiku-4-5", req=req)
```

**十一、1000 MAU 成本预估**

先给一组务实假设：

- `1000 MAU`
- 每人每月 `12` 次学习会话
- 每次 `8` 轮
- 每轮平均：
  - 输入 `1800` tokens
  - 输出 `280` tokens
- 90% 主对话用 Sonnet 4.5
- 10% 走 Haiku 4.5 或摘要任务
- 未计入图片、多模态、工具调用
- 未计入长上下文 premium rate
- 若启用 prompt caching，实际还可更低

月 token 量：

- 总轮数：`1000 * 12 * 8 = 96,000`
- 输入：`96,000 * 1,800 = 172.8M`
- 输出：`96,000 * 280 = 26.88M`

若全部 Sonnet 4.5：

- 输入成本：`172.8 * $3 = $518.4`
- 输出成本：`26.88 * $15 = $403.2`
- 合计：`$921.6 / 月`

若 90% Sonnet + 10% Haiku：

- Sonnet 部分：约 `$829.4`
- Haiku 部分：输入 `17.28M * $1 = $17.28`，输出 `2.688M * $5 = $13.44`
- 合计：约 `$860.1 / 月`

建议给业务侧报三档：

| 档位 | 假设 | 估算月成本 |
|---|---|---|
| 低 | 8 次会话/月，6 轮/次，1500 in / 220 out | `$350-$450` |
| 中 | 12 次会话/月，8 轮/次，1800 in / 280 out | `$860-$930` |
| 高 | 20 次会话/月，10 轮/次，2200 in / 350 out | `$2200-$2400` |

降本手段：

- 摘要压缩用 Haiku
- system prompt + lesson context 用 prompt caching
- recent window 严格控长
- assistant 输出限制在 `150~350 tokens`
- 对“闲聊/重复追问”启用短回复模板

### 3. `app/services/mastery_engine.py`

```python
from dataclasses import dataclass
from typing import Literal


@dataclass
class SocraticPolicy:
    mode: Literal["guided", "balanced", "question_only"]
    hint_budget: int
    max_questions_per_turn: int
    allow_direct_answer: bool
    require_student_attempt_first: bool


def policy_from_mastery(mastery: float) -> SocraticPolicy:
    if mastery < 0.3:
        return SocraticPolicy("guided", 3, 1, False, False)
    if mastery <= 0.7:
        return SocraticPolicy("balanced", 2, 1, False, True)
    return SocraticPolicy("question_only", 0, 2, False, True)


def update_mastery(
    current: float,
    answer_quality: float,
    needed_hints: int,
    correctness: float,
) -> float:
    delta = 0.15 * answer_quality + 0.15 * correctness - 0.08 * needed_hints
    next_value = max(0.0, min(1.0, current + delta))
    return round(next_value, 3)
```

class MemoryManager:
    def __init__(self, recent_window: int = 12):
        self.recent_window = recent_window

    def build_context(
        self,
        recent_messages: List[Dict[str, str]],
        latest_summary: dict | None,

        if latest_summary:

                "role": "user",

        context.extend(recent_messages[-self.recent_window:])

### 7. `app/services/interrupt_registry.py`

```python
import asyncio
from uuid import UUID


class InterruptRegistry:
    def __init__(self):
        self._tasks: dict[str, asyncio.Task] = set()
        self._cancelled: set[str] = set()

    def register(self, response_id: UUID, task: asyncio.Task) -> None:
        self._tasks[str(response_id)] = task

    def unregister(self, response_id: UUID) -> None:
        self._tasks.pop(str(response_id), None)
        self._cancelled.discard(str(response_id))

    def cancel(self, response_id: UUID) -> bool:
        key = str(response_id)
        self._cancelled.add(key)
        task = self._tasks.get(key)
        if task and not task.done():
            task.cancel()
            return True
        return False

    def is_cancelled(self, response_id: UUID) -> bool:
        return str(response_id) in self._cancelled


interrupt_registry = InterruptRegistry()
```

```python
import asyncio
from uuid import uuid4
from fastapi import Request
from fastapi.responses import StreamingResponse

from app.core.config import settings
from app.services.anthropic_client import AnthropicService
from app.services.interrupt_registry import interrupt_registry
from app.services.mastery_engine import policy_from_mastery
from app.services.prompt_builder import build_system_prompt
from app.services.memory_manager import MemoryManager
from app.utils.sse import sse_event


class DialogueOrchestrator:
    def __init__(self):
        self.anthropic = AnthropicService()
        self.memory = MemoryManager(settings.recent_message_window)

    async def stream_chat(
        self,
        request: Request,
        conversation: dict,
        user_message: str,
        recent_messages: list[dict],
        latest_summary: dict | None,
    ) -> StreamingResponse:
        response_id = uuid4()
        mastery = float(conversation["mastery"])
        policy = policy_from_mastery(mastery)

        system_prompt = build_system_prompt(
            course_name=conversation.get("course_name", ""),
            lesson_name=conversation.get("lesson_name", ""),
            student_profile=conversation.get("student_profile", "普通本科生"),
            mastery=mastery,
            policy=policy,
            assessment_mode=conversation.get("assessment_mode", False),
            known_concepts=conversation.get("known_concepts", ""),
            weak_concepts=conversation.get("weak_concepts", ""),
            recent_misconceptions=conversation.get("recent_misconceptions", ""),
        )

        messages = self.memory.build_context(recent_messages, latest_summary)
        messages.append({"role": "user", "content": user_message})

        async def event_generator():
            current_model = settings.anthropic_primary_model
            partial_text = ""

            yield sse_event("session.started", {
                "response_id": str(response_id),
                "model": current_model,
            })

            try:
                stream_cm = await self.anthropic.stream_messages(
                    model=current_model,
                    system=system_prompt,
                    messages=messages,
                    max_tokens=settings.stream_max_tokens,
                )

                async with stream_cm as stream:
                    async for text in stream.text_stream:
                        if await request.is_disconnected() or interrupt_registry.is_cancelled(response_id):
                            yield sse_event("interrupted", {"reason": "client_abort"})
                            return

                        partial_text += text
                        yield sse_event("delta", {"text": text})

                    final = await stream.get_final_message()
                    yield sse_event("usage", {
                        "input_tokens": final.usage.input_tokens,
                        "output_tokens": final.usage.output_tokens,
                    })
                    yield sse_event("done", {"response_id": str(response_id)})

            except Exception:
                if current_model != settings.anthropic_fallback_model:
                    yield sse_event("error", {
                        "code": "primary_failed",
                        "message": "fallback_to_haiku"
                    })
                raise

        task = asyncio.current_task()
        if task:
            interrupt_registry.register(response_id, task)

        return StreamingResponse(
            event_generator(),
            media_type="text/event-stream",
            headers={
                "Cache-Control": "no-cache",
                "Connection": "keep-alive",
                "X-Accel-Buffering": "no",
            },
        )
```

`useSSEChat.ts` 核心思路：

- 用 `fetch` 发起 `POST`
- 用 `ReadableStream` 逐块读取
- 解析 SSE 帧
- `AbortController` 支持停止
- 新提问前先打断旧响应

示例：

```tsx
import { useRef, useState } from "react";

export function useSSEChat() {
  const abortRef = useRef<AbortController | null>(null);
  const [streaming, setStreaming] = useState(false);

  async function sendMessage(payload: any, handlers: {
    onDelta: (text: string) => void;
    onDone: () => void;
    onStarted: (meta: any) => void;
    onError: (err: any) => void;
  }) {
    abortRef.current?.abort();

    const controller = new AbortController();
    abortRef.current = controller;
    setStreaming(true);

    try {
      const res = await fetch("/api/v1/chat/stream", {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify(payload),
        signal: controller.signal,
      });

      const reader = res.body?.getReader();
      const decoder = new TextDecoder("utf-8");
      let buffer = "";

      while (reader) {
        const { done, value } = await reader.read();
        if (done) break;

        buffer += decoder.decode(value, { stream: true });
        const frames = buffer.split("\n\n");
        buffer = frames.pop() || "";

        for (const frame of frames) {
          const eventMatch = frame.match(/event:\s*(.+)/);
          const dataMatch = frame.match(/data:\s*(.+)/);
          if (!eventMatch || !dataMatch) continue;

          const event = eventMatch[1].trim();
          const data = JSON.parse(dataMatch[1]);

          if (event === "session.started") handlers.onStarted(data);
          if (event === "delta") handlers.onDelta(data.text);
          if (event === "done") handlers.onDone();
          if (event === "error") handlers.onError(data);
        }
      }
    } catch (e) {
      if ((e as Error).name !== "AbortError") handlers.onError(e);
    } finally {
      setStreaming(false);
    }
  }

  function interrupt() {
    abortRef.current?.abort();
  }

  return { sendMessage, interrupt, streaming };
}
```
